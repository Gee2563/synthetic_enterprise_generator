# Examples

The examples below are shortened from real outputs generated by the current pipeline with fixed seeds. They illustrate shape and behavior, not only idealized pseudo-records.

## Relevant Vs Noisy Rows

### Relevant Email

```json
{
  "source_system": "email",
  "email_id": "email_62108bb718b43bb7",
  "thread_id": "thread_3547acd125503db9",
  "subject": "Confirmed attendees for Quarterly review with Davis-Andrews",
  "body": "Confirmed attendees for Quarterly review with Davis-Andrews at Davis-Andrews: Todd Oliver, Alicia Taylor.",
  "account_id": "account_65da45bb236b0b02",
  "event_id": "event_a7d9d13ba78691ce",
  "primary_category": "event_attendance",
  "is_relevant": true,
  "relevance_reason": "Attendance is grounded in event event_a7d9d13ba78691ce: Confirmed attendee list is attached to the customer review."
}
```

Why it is relevant:

- category is `event_attendance`
- the event id is present
- the reason points to explicit attendee evidence
- provenance is strong

### Noisy Slack Message

```json
{
  "source_system": "slack",
  "slack_message_id": "slack_message_a46204705233ad33",
  "channel_name": "#watercooler",
  "body": "morning all",
  "primary_category": "greetings",
  "is_relevant": false,
  "relevance_reason": "Greeting only.",
  "provenance": null
}
```

Why it is noise:

- no account, event, opportunity, or ticket linkage
- no business obligation
- the taxonomy is explicitly non-relevant

## Hard Negatives

Hard negatives contain topical overlap with positives but still fail the relevance test.

### Email Hard Negative

```json
{
  "source_system": "email",
  "subject": "Next week review timing for Davis-Andrews",
  "body": "Let's discuss the quarterly review with davis-andrews logistics next week after travel is rebooked. No customer decision is needed in this thread.",
  "event_id": "event_a7d9d13ba78691ce",
  "primary_category": "scheduling_only",
  "is_relevant": false,
  "relevance_reason": "Calendar logistics are weakly tied to event event_a7d9d13ba78691ce: Event timing is mentioned without attendance or follow-up commitment."
}
```

Why it is a hard negative:

- it mentions the customer review
- it is linked to a real event
- it looks superficially similar to a follow-up thread
- it still lacks a true attendance, blocker, or follow-up signal

## Cross-System Consistency

The same business event can appear differently in each system while keeping shared ids and facts.

### Shared Facts

- account: `account_65da45bb236b0b02`
- event: `event_a7d9d13ba78691ce`
- ticket: `ticket_issue_9689393d5af6f8a1`
- opportunity: `opportunity_e58fb3143e818fe4`

### Email

```json
{
  "source_system": "email",
  "event_id": "event_a7d9d13ba78691ce",
  "subject": "Confirmed attendees for Quarterly review with Davis-Andrews",
  "primary_category": "event_attendance"
}
```
